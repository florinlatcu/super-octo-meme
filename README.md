# Cărți de învățat Rust

Acest repository este jurnalul meu de învățare pentru Rust, construit pas cu pas pe baza cărții:
**Learn Rust in a Month of Lunches**.

## De ce țin totul în limba română

Îmi place mult limba română și vreau să învăț Rust într-un mod cât mai natural pentru mine.
Când citesc explicațiile în română, înțeleg mai bine conceptele și pot fixa mai ușor ideile.

## Cum este organizat proiectul

- `src/main.rs` – exemple și exerciții implementate pe secțiuni din carte.
- `notes.md` – rezumate scurte (5 rânduri) pentru fiecare secțiune parcursă.
- `book/` – materialul sursă folosit pentru studiu.

Funcțiile din `main.rs` folosesc prefixul `lunches_` ca să fie clar că lucrez pe cartea
**Learn Rust in a Month of Lunches** (ex: `lunches_1_1`, `lunches_1_2`).

## Ritm de studiu

- 1 oră pe zi, în zile lucrătoare
- citit + implementat + notițe + commit/push

Scopul meu este progres constant, cu explicații clare în română și cod care rulează.
